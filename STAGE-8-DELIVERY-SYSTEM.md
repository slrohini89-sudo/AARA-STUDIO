## 1. Objective of the Delivery System

The goal of this system is to ensure every completed freelance project is packaged cleanly, named systematically, and delivered with clarity. A structured delivery process reflects high professionalism, eliminates confusion for the client, and builds long-term trust.

---

## 2. Standard Client Folder Structure

For every client project, maintain this exact, clean folder hierarchy:

```
[Client Name]
│
├── Final PNG/
├── Final JPG/
├── Source file if included/
├── Copy-content/
└── Other assets/
```

### Folder Breakdown
* `Final PNG/`: High-resolution, lossless PNG files (ideal for digital post clarity and graphics with transparency).
* `Final JPG/`: Standard high-resolution JPG files (lightweight, ready for direct social media upload).
* `Source file if included/`: Editable files (e.g., PSD, AI, or editable project links) **ONLY if explicitly agreed in the project scope**.
* `Copy-content/`: Text copy, captions, or brief notes provided by the client.
* `Other assets/`: Brand logos, raw images, fonts, or references provided by the client.

---

## 3. File Naming Convention

Every file must follow a consistent, easily identifiable naming pattern:

$$\text{clientname\_designtype\_number.extension}$$

### Standard Examples:
* `cafedelight_instagram_post_01.png`
* `cafedelight_instagram_post_02.png`
* `cafedelight_carousel_slide_01.jpg`
* `cafedelight_promotional_poster_01.png`
* `cafedelight_event_poster_01.jpg`
* `cafedelight_festival_creative_01.png`

### Strict Rule on Filenames:
* **NEVER use messy or chaotic filenames** such as:  
  `finalfinal2_REALFINAL.png`, `post_updated_v3_edit.jpg`, or `Untitled-1.png`.

## 4. Delivery Workflow (Step-by-Step)

```
Step 1: Complete all agreed custom designs
                  ↓
Step 2: Complete agreed revisions (1–2 rounds as agreed)
                  ↓
Step 3: Confirm client approval & confirm remaining 50% balance payment
                  ↓
Step 4: Export final graphics in agreed formats (PNG / JPG)
                  ↓
Step 5: Rename every file following the standard convention
                  ↓
Step 6: Sort files into the respective subfolders
                  ↓
Step 7: Upload / package folder (e.g., organized Google Drive link or ZIP)
                  ↓
Step 8: Send the professional delivery message to the client
```

---

## 5. Final Delivery Checklist

Before sending the delivery link to the client, verify every item:
- [ ] Are all agreed designs present and accounted for?
- [ ] Have all requested revisions from the agreed round been accurately applied?
- [ ] Are all files named using `clientname_designtype_number.ext`?
- [ ] Are files sorted into `Final PNG/` and `Final JPG/` folders?
- [ ] Are source files excluded unless explicitly part of the agreed quote?
- [ ] Has the remaining 50% payment been confirmed?
- [ ] Are the folder sharing permissions set to "Anyone with the link can view/download"?
