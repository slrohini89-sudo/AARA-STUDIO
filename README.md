## ✦ Tech Stack & Architecture

- **Frontend:**
  - Semantic HTML5 with accessibility attributes and SEO metadata.
  - Vanilla CSS3 with custom CSS Custom Properties (`--bg-black`, `--champagne`, `--bronze`, etc.), luxury typography, responsive grid & flexbox layouts, smooth micro-interactions.
  - Vanilla JavaScript for category filtering, DOM event delegation, and modal lightbox handling.
- **Typography:**
  - *Playfair Display* (Editorial headings & script accents)
  - *DM Sans* (Clean, modern body typography)
  - *Space Grotesk* (Monospace folio markers & tags)
- **Backend / Dev Server:**
  - Lightweight, zero-dependency Node.js HTTP server (`server.js`) with MIME type resolution and path security containment.

## ✦ Getting Started Locally

### Prerequisites
- [Node.js](https://nodejs.org/) (v16.0.0 or higher recommended)

### Installation & Run

1. **Clone the repository:**
   ```bash
   git clone https://github.com/slrohini89-sudo/AARA-STUDIO.git
   cd AARA-STUDIO
   ```

2. **Start the local development server:**
   ```bash
   npm run dev
   ```
   *(Alternatively: `node server.js`)*

3. **Open the browser:**
   Navigate to:
   ```text
   http://localhost:3000/
   ```
